## 执行约定

1. 一步一个 commit；每步先写/更新对应测试，再实现。
2. 每步的"完成判据"必须真实跑过（单测或命令输出），不靠口头判断。
3. 涉及外部服务（PostgreSQL / pgvector / LLM / embedding）的步骤先跑真实探针，失败就停在原地并报告。
4. 每完成一个阶段跑一次全量 `uv run pytest -q` 与 `uv run ruff check app tests scripts`。
5. 不静默降级：外部依赖不可用时分析失败，不产出半成品结论。
6. 样例文档只作回归夹具，解析规则不得硬编码 `DT_REQ_`、`3.3.`、`第5章` 这类前缀。
